# Selenium Utils

## Overview

**Selenium Utils** is a collection of utility scripts designed to streamline automated testing using Selenium. This repository contains reusable components, sample test cases, and Java-based implementations to assist developers and testers in creating robust automation frameworks.

## Features

- **Reusable Test Scripts**: Includes sample test cases written in Java.
- **Organized Directory Structure**: Clear separation of test scripts and utility files.
- **Scalable Design**: Suitable for integration into larger automation frameworks.

## Directory Structure

- **main/java/**: Contains core utility scripts.
- **main/sampleTest/**: Includes sample test implementations for demonstration purposes.
- **test/java/**: Houses test scripts for validation and testing.
- **test/sampleTest/**: Contains additional sample tests.

## Prerequisites

Before using this repository, ensure you have the following installed:

1. **Java Development Kit (JDK)** (version 8 or higher)
2. **Selenium WebDriver**
3. A compatible IDE such as IntelliJ IDEA or Eclipse
4. Maven (for dependency management)

## Getting Started

### Clone the Repository

git clone https://github.com/AutomationUser22/Selenium_Utils.git

cd Selenium_Utils/src

### Build the Project

Use Maven to build the project:

mvn clean install

### Run Tests

Navigate to the `test` directory and execute sample test cases:

mvn test
